# SmartFarm 🌾📱
SmartFarm è un'app mock-up Android sviluppata come prototipo per migliorare l’interazione uomo-macchina in un contesto di Industria 4.0.

## 🎯 Obiettivo
Progettare un’interfaccia intuitiva e user-centered per un'app Android nel settore agritech.

## 🛠️ Tecnologie Utilizzate
⦁	Android Studio.
⦁	Java.

## 📐 Principi Seguiti
⦁	Human-Centered Design.
⦁	Usabilità e semplicità.
⦁	Feedback immediato per l’utente.

## 🖼️ Demo
🎬 Video dimostrativo: [YouTube](https://www.youtube.com/watch?v=E8BrAvWxCx4)  
🔗 Codice completo: disponibile in questo repository

## ⚙️ Avvio del progetto
1.	Apri il progetto in Android Studio.
2.	Avvia l’emulatore o un dispositivo reale.
3.	Esegui la build e testa l’interfaccia.

## 📄 Stato del progetto
Mock-up funzionale completato per fini accademici.
